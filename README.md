### Isaac Kang

I study philosophy at Princeton (A.B., Philosophy of Science track, class of 2029). I'm interested in how minds work and in building systems that model them, where philosophy of mind, cognitive science and machine learning meet.

I design the architecture, write the spec and set the checks every change has to pass; AI coding agents write the code. The decision logs in my repos are the best record of my part.

Projects:

- [stezu-health](https://github.com/Ik301/stezu-health): Ingest, an iPhone app (SwiftUI, HealthKit) with a FastAPI server, for logging meals from photos, workouts and weigh-ins. I use it daily. Start with [DECISIONS.md](https://github.com/Ik301/stezu-health/blob/main/DECISIONS.md).
- [princeton-events](https://github.com/Ik301/princeton-events): Princeton's public event listings as subscribable calendar feeds, refreshed every week by a scheduled job.
- [crisis-chain](https://github.com/aikhanjum/crisis-chain): a team project at the MIT Bitcoin Hackathon 2026 (People's Choice and Community Prize). On-chain humanitarian aid: regional USDC pools that reimburse NGOs against verified receipts. I worked on the idea, the UI/UX and the data sourcing.

I write essays and poems at [Connecting Dots](https://blogyk.com).
